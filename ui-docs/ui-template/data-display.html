Data display

Rows, numbers, tables, status, markers and groups. App: components/ui (RowList, KpiCount, ProgressThread, CourseStatus, CollapsibleGroup, Disclosure) and the antd skin. Course states are beads (see semester-timeline.html §B); flags are solid pips.

Rows and numbers

Facts are label → value rows (label left, value right, long values wrap). A number that matters is a serif count; part of a whole adds the progress thread with a sparkle at its tip.

Course table, file column, conflicts, row note

Tables are transparent: uppercase soft headers, hairline rows, tint on hover. The file column shows ✓ / --. A row that differs from the myBK file gets a terracotta pip before its first cell and a DiffFlag. A note opens as a blush expanded row.

Groups and disclosure
