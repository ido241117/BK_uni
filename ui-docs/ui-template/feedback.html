Feedback and overlays

Status line, notice, toast, confirm popover, modal, empty and loading states. A state the page is in is a status line; a problem to read or fix is a notice; feedback after an action is a toast. App: components/ui/Feedback.tsx, EmptyState, the antd skin.

Status line

A band on blush between two hairlines; a 24px icon ring in the tone color, bold title, muted detail or list, optional action. Gợi ý lộ trình has exactly one, between the KPI strip and the timeline.

Notice, toast, confirm

Notices are only for problems (warning, error): a 2.5px left rule, a wash, a bold title. Toasts confirm an action with the same verb as the button. Every change that writes the student's data confirms first, in one line.

Empty and loading states

Nothing to show is an invitation to act: the right character, a serif title, one sentence, the next step. Loading is a pulsing sparkle with skeleton rows shaped like the page; opening a page floats the sparkle page.
