Foundations

Palette, type, space, motifs, icons and illustrations. Values are read live from tokens.css in this folder; use the toggle (top right) for dark. Rules for choosing or changing colors: ui-docs/DESIGN-SYSTEM.md §1.3, checked by npm run contrast:check.

Palette

Light pink, line-driven: about 60% canvas, 30% blush and hairlines, 10% rose, brand blue under 1%. Every text token passes 4.5:1 on all four surfaces; sparkle and lines are decorative only.

Type

Serif (Fraunces) for what you read first; sans (Be Vietnam Pro) for everything you scan or operate. Both are self-hosted in the app with Vietnamese subsets.

Space and radius

Scale --space-1…11. Radius 4px for stamps, inputs, chips and menus; 6px for modal and disclosure; full pills only for nav items and the delta pill.

Motifs

Three motifs, each with one meaning. Rules run across the page; the timeline thread is the one line that runs down, because it is the thread motif.

Thread + beads · progress through time
Sparkle · "something is coming"
Timeline checkpoints (next, upcoming, graduation), progress tip, loading. Never an icon for something else.
Folded page · a document, the mascot

Bead family

Course states as ring shapes: see semester-timeline.html §B. A solid 6px pip is a flag on a row, never a state.

Icons

Phosphor (Regular for UI, Fill for warnings), 16–18px in controls, 14px inline. Icons take their text's color. Icon-only buttons need an aria-label.
