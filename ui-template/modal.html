Nhập tiến độ từ myBK

Trên myBK mở Tiến độ hoàn thành chương trình đào tạo, bấm Cập nhật để lấy số mới nhất. Bấm In. Ở ô Máy in đích chọn Lưu dưới dạng PDF. Lưu file rồi chọn file đó ở đây.

Kéo thả file PDF vào đây hoặc bấm nút bên dưới
  1. Trên máy tính, mở myBK trang Tiến độ hoàn thành chương trình đào tạo, bấm Cập nhật.
  2. Bấm Ctrl+A rồi Ctrl+C.
  3. Dán vào ô dưới (Ctrl+V) rồi bấm Đọc nội dung.
  4. Dấu ✓ của myBK không copy được, nên web suy “đạt” từ điểm: 4–10, 12 (miễn) và 21 (đạt) là đạt; “--” là chưa đạt.
